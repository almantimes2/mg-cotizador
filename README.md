# G2 Climas — Cotizador y Control de Ventas

Aplicación web (una sola página) para G2 Climas: cotizador, historial de ventas,
calculadora de capacidad, recordatorios de servicio y control de ingresos.

- **Funciona sin internet** (PWA instalable con service worker).
- Los datos se guardan en el propio dispositivo (localStorage).
- Se pueden compartir/combinar datos entre dispositivos desde **Ajustes → Compartir datos**.

Publicada con GitHub Pages. Para instalarla en el celular: abrir el enlace en el navegador
y elegir **"Agregar a la pantalla de inicio"**.
